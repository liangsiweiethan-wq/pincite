# Contributor Covenant Code of Conduct

## Our Pledge

We pledge to make participation in **PinCite** a harassment-free experience for everyone, regardless of background, identity, discipline, or experience level.

## Expected Behavior

- Be respectful, constructive, and precise in technical reviews and discussions.
- Focus on reproducible evidence, clear invariants, and user safety.
- Never share private research libraries, credentials, or personal data in issues or PRs.

## Enforcement

Maintainers may edit or remove comments, commits, or contributions that violate this Code of Conduct. Report concerns via GitHub's private security/maintainer channels.
